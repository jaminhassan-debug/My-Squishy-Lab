# My Squishy Lab

Complete browser-playable v0.13 cloud build with all 16 scenes and glossy image-generated artwork.

## Play online

https://jaminhassan-debug.github.io/My-Squishy-Lab/

GitHub Pages publishes this game automatically through `.github/workflows/pages.yml` whenever main is updated. If configuring hosting from scratch, open repository Settings → Pages and choose **GitHub Actions** as the source. No build command or API key is needed.

## Contents

HTML, CSS and JavaScript source, native image-generated artwork, sprite atlases, animation data and local game models are included. The welcome screen keeps its original green Play button. The vector control overhaul is absent.

For web hosting, images load from this same HTTPS origin rather than being duplicated inside a 45 MB embedded-image script. The full offline build and developer blueprint remain available separately.

## Progress

Creations, coins and settings save in this browser on this device. Hosting the game online does not add account-based cross-device save sync. Parent settings include backup export and import.

## Version

v0.13 cloud build, 1 November 2026. Art/routing checks and pouring/playground/pause regression checks passed for the source release. Real-device visual and touch review remains pending.
